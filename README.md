# Matthew Morrone

Software engineer with a linguistics degree, based in Philadelphia. I build tools for reading, sound, and writing systems, plus the occasional piece of hardware.

## Main project

**[Kioku](https://github.com/matthewmorrone/Kioku)** is an iOS app for reading, looking up, and studying Japanese, with kanji handwriting input and lyric alignment.

## Language tools

- **[diachron-db](https://github.com/matthewmorrone/diachron-db)**: a queryable, editable database of historical sound changes across languages
- **[marain](https://github.com/matthewmorrone/marain)**: an editor and reference for Marain, the constructed script from Iain M. Banks's Culture novels
- **[genlang](https://github.com/matthewmorrone/genlang)**: procedural conlang generation
- **[scriptool](https://github.com/matthewmorrone/scriptool)**: render text into an arbitrary phonetic orthography
- **[ipa](https://github.com/matthewmorrone/ipa)** and **[cmudict-ipa](https://github.com/matthewmorrone/cmudict-ipa)**: IPA tooling, and the CMU dictionary converted from Arpabet to IPA
- **[alignment](https://github.com/matthewmorrone/alignment)**: turn audio and lyrics into timed `.srt` and `.TextGrid` files with stable-ts
- **[moon](https://github.com/matthewmorrone/moon)**: synced, furigana-annotated lyric pages for Sailor Moon songs

## Research

- **[OrthographicDepth](https://github.com/matthewmorrone/OrthographicDepth)**: a paper on measuring orthographic depth via information compression and alignment

## Other tools

- **[ytdlp-firefox-extension](https://github.com/matthewmorrone/ytdlp-firefox-extension)**: run yt-dlp on the active YouTube tab from Firefox, through a native messaging host
- **[media-player](https://github.com/matthewmorrone/media-player)**: a local media server and player with a web UI
- **[morse](https://github.com/matthewmorrone/morse)**: a Morse code teacher with flashcards
- **[glyph](https://github.com/matthewmorrone/glyph)**: search across seven icon libraries at once
